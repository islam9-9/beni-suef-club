# نادي بني سويف الرياضي — بيئة التطوير

هذه بيئة محلية تجريبية على Odoo 19 Community، وليست نظام نادي مكتملًا أو بيئة إنتاج.

## ما يحتويه مستودع GitHub

ملفات مشروع النادي، سكربتات التشغيل والتحقق والنسخ الاحتياطي، نطاق العمل في `docs/PROJECT_SCOPE.md`، ومجلد `addons/` المخصص للتطوير القادم.
نسخة Odoo الرسمية المطلوبة موثقة في `source.lock.json`؛ لا ننسخ كود أودو بالكامل داخل مستودع إضافات النادي، مثل طريقة تنظيم مشروع الفندق.

قاعدة البيانات والمرفقات وكلمات المرور والنسخ الاحتياطية تبقى خارج GitHub. حفظ الكود هنا لا يُعد نسخة احتياطية لبيانات النادي ولا ينشر النظام على الإنترنت.

بعد استنساخ المشروع على نفس الجهاز، أنشئ `runtime.json` من `runtime.example.json` وحدد مجلد التشغيل الموجود. تشغيل المشروع على جهاز جديد يحتاج تجهيز Python وPostgreSQL ومصدر Odoo واستعادة قاعدة البيانات والمرفقات وإعداد الأسرار المحلية؛ المستودع الحالي ليس مثبتًا آليًا لجهاز جديد. بعض السكربتات مرتبطة بمسارات الجهاز الحالي وتحتاج مراجعة عند النقل.

## الدخول والتشغيل

- الرابط: http://127.0.0.1:8095
- قاعدة البيانات: `beni_suef_club_dev`
- المستخدم: `club.admin`
- بيانات الدخول السرية في `C:\Users\accis\ClubRuntime\access.json`، خارج مجلد المشروع وOneDrive.
- التشغيل: افتح PowerShell وشغّل `./start-club.ps1` من هذا المجلد.
- تشغيل السيرفر حاليًا يدوي؛ لا توجد خدمة بدء تلقائي عند تشغيل Windows.
- الاستماع على الجهاز المحلي فقط. لا يوجد نشر على الإنترنت أو إعداد إنتاج.

المسار الفعلي للتشغيل هو `C:\Users\accis\ClubRuntime` ومسجل في `runtime.json`. استُخدم مسار قصير لتجنب حدود طول مسارات Windows.

## المكونات

تم اختيار الأساس القياسي: جهات الاتصال، الفوترة/القيود الأساسية المتاحة في Community، المشتريات والمخازن، مع اللغة العربية ودولة مصر وعملة الجنيه المصري.
تعيين مصر والعملة لا يعني اعتماد دليل حسابات أو إعدادًا ضريبيًا أو تكاملًا مع منظومة الضرائب. تعتمد هذه الإعدادات لاحقًا مع محاسب النادي.

المصدر الرسمي المثبت على commit محدد مسجل في `C:\Users\accis\ClubRuntime\source.json`.
لا تتم إضافة مسارات إضافات الفندق أو Enterprise إلى هذه البيئة.
بيئة Python افتراضية مستقلة تستخدم مكتبات Python المثبتة حاليًا عبر system-site-packages؛ لم يتم تعديلها. يلزم تثبيت اعتماديات مستقلة ومثبتة الإصدارات قبل نقل النظام للإنتاج.
خادم PostgreSQL 16 مستقل للنادي على `127.0.0.1:5495`، وله قاعدة ودور اتصال بلا صلاحيات superuser أو إنشاء أدوار/قواعد. لا يتم تعديل أو تحديث PostgreSQL القديم المستخدم للمشروعات الأخرى.

## ما ينتظر مقابلة النادي

1. أنواع العضوية وعلاقات التابعين وشروط إضافتهم وفصلهم.
2. الرسوم والغرامات والإعفاءات وتواريخ سريانها وسلطة اعتمادها.
3. يوميات الخزنة ووسائل التحصيل والإلغاء والاسترداد والتسويات.
4. دليل الحسابات والأرصدة الافتتاحية والضرائب ومراكز التكلفة.
5. دورة المشتريات وحدود الاعتماد والاستلام والصرف.
6. الوحدات المؤجرة وكراسات الشروط والعطاءات والترسية والعقود والتأمينات والاستحقاقات.

لم تنشأ قواعد عضوية أو رسوم أو عطاءات افتراضية على أنها قواعد النادي. لا توجد بيانات أعضاء حقيقية.

## الملفات

- `start-club.ps1`: تشغيل الخدمة المحلية في الخلفية.
- `stop-club.ps1`: إيقاف أودو الخاص بالنادي فقط قبل النسخ الاحتياطي.
- `backup-club.py`: نسخة مستقلة من PostgreSQL وملفات المرفقات؛ يشترط إيقاف أودو أولًا.
- `verify-club.py`: اختبار صفحة الدخول والمصادقة والواجهة والملفات وصلاحيات قاعدة البيانات، دون طباعة أسرار.
- `setup-postgres.py`: سجل إعداد ونقل لمرة واحدة إلى PostgreSQL 16؛ لا يعاد تشغيله على البيئة الحالية.
- `provision.py`: إنشاء قاعدة ودور جديدين؛ يرفض الكتابة فوق قاعدة أو دور موجودين. لا تعِد تشغيله على البيئة المنشأة.
- `bootstrap.py`: إعداد أولي ينفذ عبر Odoo shell على قاعدة النادي فقط؛ ليس للتشغيل المتكرر بعد بدء العمل.
- `addons/`: موضع إضافات النادي عند اعتماد التصميم.

احتفظ بالنسخ الاحتياطية شاملة قاعدة البيانات وملفات المرفقات، واختبر الاستعادة قبل اعتماد أي استخدام فعلي.

تمت استعادة قاعدة نقطة البداية من نسخة PostgreSQL القديمة إلى خادم PostgreSQL 16 المستقل ثم اختبار الدخول. توجد أيضًا نسخة أولية غير مستخدمة بنفس اسم قاعدة النادي على خادم PostgreSQL القديم (5432) من مرحلة التجهيز؛ جميع ملفات التشغيل الحالية تشير إلى 5495 فقط.
أداة RTL CSS مثبتة محليًا تحت مجلد التشغيل، ويضبط سكربت التشغيل مسار Node.js الخاص بأدوات الجهاز. طباعة PDF تستخدم wkhtmltopdf المتوفر على الجهاز، ولم تعتمد قوالب إيصالات النادي بعد.
