# هوية نادي بني سويف الرياضي

تخصيص بصري مستقل لقاعدة النادي: الشعار المقدم من المستخدم، اسم الشركة، أيقونة المتصفح، شاشة الدخول وألوان الواجهة (كحلي #142E42، أزرق #245B94، أحمر #AA2B22 وذهبي #D6A62B).

تم الاحتفاظ بملف الشعار الأصلي دون تعديل. ترخيص كود الإضافة LGPL-3 لا يمنح حقوقًا في شعار النادي أو علامته.

التثبيت الأول يضبط شعار الشركة الرئيسية واسمها والألوان. لا يغير العضويات أو الأسعار أو القيود المحاسبية. اسم الشركة الجديد قد يظهر على المستندات القياسية التي تستخدم اسم الشركة وشعارها؛ لم يتم تصميم قوالب إيصالات مخصصة.

نسخة ما قبل التثبيت: C:\Users\accis\ClubRuntime\backups\20260927-140811. نجح التثبيت واختبار المصادقة وتحميل حزم الواجهة، وتمت معاينة شاشة الدخول في المتصفح.

إضافة خاصة بالنادي وليست ضمن حزمة الأساس العامة. build-basic.py يستخدم قائمة صريحة تسمح بنسخ community_workspace فقط من إضافات المشروع المحلية. إلغاء تثبيت الإضافة لا يعيد تلقائيًا اسم الشركة والشعار والألوان القديمة؛ يمكن ضبطها من الإعدادات أو الاستعادة من النسخة الاحتياطية المناسبة.
