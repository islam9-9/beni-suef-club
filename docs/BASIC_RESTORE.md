# النسخة الأساسية العامة

نسخة Odoo 19 Community جديدة، تشمل الحسابات المجانية من Cybrosys وواجهة MuK وتخصيص Community Workspace. لا تشمل بيانات النادي أو العضويات أو فواتير وحركات فعلية. الشركة الافتراضية Community Business، اللغة العربية والعملة المصرية. دليل الحسابات والسياسات المحاسبية يحتاجان إعدادًا لكل مشروع؛ اجتياز الاختبارات التقنية ليس اعتمادًا محاسبيًا.

## المحتويات

- database.dump وfilestore.zip: قاعدة الأساس ومرفقاتها.
- addons: التخصيص العام والإضافات الخارجية بإصدارات مثبتة.
- odoo-community-source.zip: كود أودو الرسمي المطابق.
- source.lock.json وthird-party.lock.json: مصادر وإصدارات الكود.
- verification.json: نتيجة الاستعادة الفعلية والتحقق من الوحدات وخلو الحركات.
- SHA256.json: بصمات الملفات للتحقق من سلامتها.

لا توجد كلمات مرور أو إعدادات اتصال خاصة ضمن الحزمة. كلمة مرور المدير عشوائية وغير محفوظة؛ يجب تعيين كلمة جديدة عند الاستعادة. المهام المجدولة معطلة ولا يوجد خادم إرسال بريد. فعّل المهام المطلوبة بعد إعداد المشروع ومراجعتها.

## الاستعادة على Windows

هذه حزمة أساس وليست مثبّتًا مستقلًا بنقرة واحدة. تحتاج Python 3.12 مع متطلبات أودو وrequirements.txt، وPostgreSQL 16، وrtlcss لتوليد CSS العربي، وwkhtmltopdf للتقارير PDF. يمكن استخدام بيئة التشغيل الموجودة على هذا الجهاز. احتفظ بتراخيص الإضافات عند إعادة التوزيع.

1. فك مصدر أودو في مجلد جديد، وثبت المتطلبات في بيئة Python منفصلة.
2. أنشئ مستخدم PostgreSQL محدودًا للمشروع، وجهّز ملف odoo.conf خاصًا خارج Git. ضع db_name باسم قاعدة جديدة وdb_host وdb_port وdb_user وdb_password وdata_dir وaddons_path (إضافات أودو الرسمية ثم مجلد addons في هذه الحزمة). اربط الخدمة محليًا مبدئيًا واختر منفذًا مختلفًا عن النادي 8095.
3. اضبط PGUSER وPGPASSWORD مؤقتًا في جلسة PowerShell لحساب إنشاء قواعد PostgreSQL. لا تكتب كلمات المرور في ملفات مشتركة أو Git.
4. شغّل restore-basic.py بواسطة Python الخاص بأودو مع --config و--pg-bin و--odoo و--database. البرنامج يتحقق من البصمات ويرفض استبدال قاعدة موجودة ويطلب كلمة مرور مدير جديدة مخفية.
5. شغّل odoo-bin باستخدام ملف إعدادات المشروع، ثم ادخل باسم admin والكلمة التي اخترتها. اضبط الشركة والمستخدمين والصلاحيات والحسابات والضرائب والنسخ الاحتياطي قبل التشغيل الفعلي.

## تحديث الأساس

من مستودع المشروع على الجهاز الحالي شغّل build-basic.py ببيئة Python الخاصة بالنادي بعد اعتماد تغييرات عامة. كل تشغيل يبني قاعدة جديدة من الصفر ويختبر استعادتها ويحفظ مجلدًا مؤرخًا في D:\odoo com\basic ويحدّث LATEST.json فقط بعد النجاح. لا ينسخ بيانات النادي ولا يستبدل النسخ السابقة. التحديث يدوي مع التطوير، وليس خدمة نسخ احتياطي تلقائية. قواعد البناء والاختبار تبقى محلية للمراجعة؛ لا تشغّل عليها أعمالًا فعلية.
